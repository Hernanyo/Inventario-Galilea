\# Manual: Mantenciones



Flujo para gestionar mantenciones.



\## Crear

1\. Menú → Mantenciones → \*\*Nueva mantención\*\*.

2\. Selecciona Activo, Tipo, Prioridad, Responsable y descripción.

3\. Guardar.



\## Cambiar estado

\- Desde \*\*Editar\*\* cambia el estado (Pendiente, En curso, Finalizada, etc).



\## Historial de mantenciones

\- Desde la lista, botón \*\*Historial\*\* para ver eventos (CREAR, EDITAR, ADJUNTAR, QUITAR\_ADJUNTO).



\## Comentarios

\- Si hay comentarios largos, usa el botón \*\*Ver\*\* para abrir el modal.
