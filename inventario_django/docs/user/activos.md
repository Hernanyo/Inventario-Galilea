\# Manual: Activos



Esta sección explica cómo gestionar activos.



\## Crear

1\. Menú → Activos → \*\*Nuevo activo\*\*.

2\. Completar formulario.

3\. Guardar.



\## Editar

1\. Menú → Activos → botón \*\*Editar\*\* en la fila.

2\. Actualizar valores y \*\*Guardar\*\*.



\## Eliminar (lógico)

\- Usa \*\*Eliminar\*\*. El registro queda oculto, pero no se borra físicamente.



\## Historial

\- Botón \*\*Historial\*\* en la fila para ver cambios del activo.



\## Observaciones

\- En la lista, usa el botón \*\*Ver\*\* en la columna \*Obs.\* para abrir el modal.
